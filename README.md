# CinemaHub (WinForms + SQL Server)

Швидкий старт:
1. SSMS або Visual Studio (SQL Server Object Explorer, (localdb)\MSSQLLocalDB) -> виконати `SQL\01_CinemaHub_DB.sql`.
2. Відкрити `CinemaHub.sln` у Visual Studio 2019/2022 (навантаження ".NET desktop development").
3. За потреби змінити рядок підключення в `CinemaHub\App.config`.
4. F5.

Детально - у файлі `Інструкція.docx`.
